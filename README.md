## Publish on GitHub Pages

For a repository named `elimartinezsancho.github.io`, GitHub normally publishes the
site automatically from the `main` branch after the first upload.

If it does not appear after a few minutes:

1. Open the repository **Settings**
2. Select **Pages**
3. Under **Build and deployment**, choose **Deploy from a branch**
4. Select the **main** branch and **/(root)**
5. Save

## Editing

You can edit files directly on GitHub using the pencil icon. Replace the placeholder
publication entries and `#` links in `index.html` with your real information.
